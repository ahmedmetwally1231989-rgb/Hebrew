# حافظ العبرية — مشروع أندرويد

هذا مشروع Android Studio يغلّف ملف HTML الأصلي داخل WebView، مع الاحتفاظ بواجهة التطبيق ووظائف البطاقات، قائمة الكلمات، الاستيراد، الإحصائيات، المظهر الداكن/الفاتح، والتخزين المحلي. تمت إضافة جسر لإظهار إشعارات أندرويد الأصلية عند استدعاء الإشعار من داخل التطبيق.

## مهم بخصوص الإشعارات
- إشعارات أندرويد الأصلية تظهر عندما يستدعي التطبيق وظيفة الإشعار أثناء تشغيل صفحة التطبيق.
- مؤقت الإشعارات في ملف HTML يعتمد على `setInterval`؛ لذلك يتوقف أو قد يتأخر عندما يضع أندرويد التطبيق في الخلفية أو يقيّده. هذا المشروع لا يدّعي توفير جدولة موثوقة بالخلفية/والشاشة مقفولة.
- زر الإذن يطلب إذن الإشعارات على Android 13 وما بعده.
- الواجهة تعتمد على مكتبات وخطوط من الإنترنت (Tailwind وFont Awesome وGoogle Fonts)، لذا يلزم الإنترنت لبعض التنسيقات. التخزين المحلي للكلمات يبقى داخل بيانات التطبيق.

## بناء APK عبر GitHub Actions
1. فك ضغط المشروع وارفع محتوياته إلى مستودع GitHub جديد.
2. افتح تبويب **Actions** وشغّل **Build Android APK** (أو ادفع commit إلى فرع `main`).
3. افتح عملية التشغيل الناجحة، ثم نزّل ملف **HafizHebrew-debug-apk** من قسم Artifacts.
4. فك ضغط الملف على الهاتف وثبّت `app-debug.apk`. قد تحتاج السماح بالتثبيت من هذا المصدر.

## البناء محليًا
افتح المجلد في Android Studio حديث، وثبّت Android SDK Platform 35، ثم شغّل مهمة `assembleDebug`.

هذا APK تجريبي موقّع بمفتاح debug، وليس إصدار متجر Play.
